# Copycode 0.9.1

Copy code blocks to clipboard. Developed by Steffen Schultz.

<p align="center"><img src="screenshot.png" alt="Screenshot"></p>

## How to install an extension

[Download ZIP file](https://github.com/schulle4u/yellow-copycode/archive/refs/heads/main.zip) and copy it into your `system/extensions` folder. [Learn more about extensions](https://github.com/annaesvensson/yellow-update).

## How to copy a code block

This extension automatically creates a "copy code" button below each fenced or indented code block in a page. Click the button to copy the content to your clipboard.
